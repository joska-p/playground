### buildTree()

> **buildTree**(`structureRng`, `channelRng`, `currentDepth`, `maxDepth`, `rules?`): [`ExpressionNode`](types.mdx#expressionnode)

Defined in: [tree/build.ts:46](https://github.com/joska-p/playground/blob/b4f351259e36f80b1230d3ac42dacf689d4443d9/packages/randomart-engine/src/tree/build.ts#L46)

Builds one expression tree, recursively picking rules from a pool weighted by each rule's
`weight`. Structural decisions at shallow depth come from `structureRng` (shared across channels)
so R/G/B trees share shape; deeper nodes use `channelRng`.
