# @repo/radu-machine-learning

> A quiet gallery of hand-drawn strokes — every scribble, car, and house
> from a student's handwriting sessions, frozen into SVGs and laid out
> in rows for machine learning exploration.

---

## Essence

Radu Machine Learning is a stroke data viewer built for a
[machine learning course](https://www.youtube.com/playlist?list=PLB0Tybl0UNfYe9aJXfWw-Dw_4VnFrqRC4).
It takes raw pen-sample recordings — sequences of `[x, y]` coordinates
captured as someone draws simple objects — and turns them into a browsable
grid of labelled images. The data was collected across multiple sessions
between late 2022 and mid-2023, first for
[Phase 1](https://github.com/gniziemazity/ml-course) and later for
[Phase 2](https://github.com/gniziemazity/ml-course-phase-2) of the course.

The interesting thing about stroke data is how much it reveals about a
drawer's hand. Each path is a trail of intent — where the pen lifted,
where it hesitated, where a curve was committed in a single sweep. This
viewer pairs the raw material with two lightweight companions: a sketchpad
to draw your own strokes, and a chart that drops them into the dataset's
feature space. The pipeline stays honest — every drawing is presented as
it was recorded, one beside the next, so a learner can see the shapes a
classifier would have to separate.

## Quick Start

Run the explorer on its own:

```bash
pnpm dev --filter @repo/radu-machine-learning
```

Or embed it in your own project:

```bash
pnpm add @repo/radu-machine-learning
```

```tsx
import { App } from '@repo/radu-machine-learning/radu-machine-learning';
import '@repo/radu-machine-learning/styles';

export default function Page() {
    return <App />;
}
```

`App` fills its container — render it somewhere full-screen so the gallery
has room. The `styles` import brings in the Tailwind theme the explorer is
styled with.

## Usage

`App` renders two panes: the stroke gallery on the left and a control panel
on the right.

- **Gallery** — one row per student, with a labelled card for each drawing.
  Click a card to highlight it; the selected drawing also scrolls into view
  when targeted from the panel.
- **Sketchpad** — a canvas to draw your own strokes. Pick a stroke colour,
  undo the last path, clear the pad, or export the paths as `paths.json`.
- **Chart** — a scatter plot of every drawing by `Path Count` and
  `Point Count`, the two features the dataset is labelled with. The current
  sketchpad drawing appears as a live point, so you can see where your hand
  lands relative to the recorded ones.

`App` takes an optional `baseUrl` prop that prefixes the drawing-image URLs
(they are served from `<baseUrl>radu-img/{id}.svg`); it defaults to `/`.

## Patterns & Gotchas

- **Drawings are pre-rendered, not replayed.** Each stroke is frozen into a
  single `<polyline>` SVG at build time; the gallery renders `<img>` tags
  pointing at `radu-img/{id}.svg`. No stroke coordinates are interpreted at
  runtime.
- **SVGs are keyed by id, not label.** The auto-incremented id maps to both
  the SVG filename and the chart point — the label is a separate attribute.
- **The dataset is generated by scripts.** `gen-dataset` reads raw session
  JSON and emits the SVGs plus a TypeScript module; `extract-features`
  computes the two features. Their output under `src/data/dataset/ts_objects/`
  is gitignored.

## Field Notes

- **The Catalyst:** Machine learning courses need labelled datasets.
  Adrian Perrig's
  [Random-Art paper](https://www.randomart.org/) showed that even
  simple deterministic algorithms produce surprisingly rich visual
  output from short seed strings — and the inverse question is
  equally interesting: what does a human hand produce when asked to
  draw the same object five times? This package collects those
  drawings as structured stroke data, ready for feature extraction
  and classifier training.

- **Quirks & Anomalies:** The build pipeline does the heavy lifting.
  `dataset_generator.ts` reads raw session JSON from
  `src/data/subset-samples/`, assigns an auto-incremented id to each
  drawing, and emits three artefacts: per-drawing SVG files into
  `public/radu-img/`, per-drawing JSON, and a TypeScript module
  (`samples.ts`) bundling the sample metadata as a `const` array.
  `features-extractor.ts` then reads each drawing's paths back and
  computes its `[Path Count, Point Count]` feature vector. At runtime
  the components never touch stroke coordinates directly — they render
  `<img>` tags pointing at the pre-generated SVGs, so the entire stroke
  is a single vector path with no intermediate point rendering.

- **Future Horizons:** Interactive stroke playback, where each path
  animates pen-down movement in real time, would make the data feel
  more like a living recording. Export to CSV or NumPy-friendly
  formats would lower the barrier to feeding this data into
  scikit-learn or TensorFlow.
