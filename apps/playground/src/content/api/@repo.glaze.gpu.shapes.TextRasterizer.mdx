## Classes

### TextRasterizer

Defined in: [gpu/shapes/TextRasterizer.ts:55](https://github.com/joska-p/playground/blob/b4f351259e36f80b1230d3ac42dacf689d4443d9/packages/glaze/src/gpu/shapes/TextRasterizer.ts#L55)

Rasterizes text on an offscreen 2D canvas and uploads it as a texture, cached by (text, font) in
an LRU of 128 entries. Rasterization runs at 2× the requested size so edges stay crisp when
scaled.
