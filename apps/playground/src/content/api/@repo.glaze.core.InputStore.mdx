### InputStore

Defined in: [core/InputStore.ts:29](https://github.com/joska-p/playground/blob/b4f351259e36f80b1230d3ac42dacf689d4443d9/packages/glaze/src/core/InputStore.ts#L29)

Raw pointer, wheel, and keyboard signal bus attached to a canvas. Pointer positions are
canvas-relative CSS pixels; transient state (`wasKeyPressed`, `wheelDelta`) is cleared by
`endFrame()`.
