## 🎯 Intention & Concept

Radu Machine Learning is a stroke data viewer built for a [machine learning course](https://www.youtube.com/playlist?list=PLB0Tybl0UNfYe9aJXfWw-Dw_4VnFrqRC4). It takes raw pen-sample recordings — sequences of `[x, y]` coordinates captured as someone draws simple objects — and turns them into a browsable grid of labelled images. The data was collected across multiple sessions between late 2022 and mid-2023, first for [Phase 1](https://github.com/gniziemazity/ml-course) and later for [Phase 2](https://github.com/gniziemazity/ml-course-phase-2) of the course.

The interesting thing about stroke data is how much it reveals about a drawer's hand. Each path is a trail of intent — where the pen lifted, where it hesitated, where a curve was committed in a single sweep. This viewer pairs the raw material with two lightweight companions: a sketchpad to draw your own strokes, and a chart that drops them into the dataset's feature space. The pipeline stays honest — every drawing is presented as it was recorded, one beside the next, so a learner can see the shapes a classifier would have to separate.

## ⚠️ Patterns & Gotchas

- **Drawings are pre-rendered, not replayed.** Each stroke is frozen into a single `<polyline>` SVG at build time; the gallery renders `<img>` tags pointing at `radu-img/{id}.svg`. No stroke coordinates are interpreted at runtime.
- **SVGs are keyed by id, not label.** The auto-incremented id maps to both the SVG filename and the chart point — the label is a separate attribute.
- **The dataset is generated by scripts.** `gen-dataset` reads raw session JSON and emits the SVGs plus a TypeScript module; `extract-features` computes the two features. Their output under `src/data/dataset/ts_objects/` is gitignored.
- **`baseUrl` prop.** Drawing-image URLs are served from `<baseUrl>radu-img/{id}.svg`; it defaults to `/`.
