# Codex — Centralized Knowledge & Documentation Hub

Welcome to **Codex**, the centralized documentation, knowledge, and workshop hub for the monorepo.

## 📂 Directory Structure

```text
codex/
├── docs/                # Internal documentation (manual guides, conventions, explanations, how-tos)
├── knowledge/           # Accumulated technical knowledge base (formerly _KNOWLEDGE/)
└── ateliers/             # Documentation workshops, tooling, scripts, and build pipeline artifacts
    ├── typedoc-pipeline/# Typedoc telemetry and package README sync tools
    └── templates/       # Documentation and concept templates
```

## 🎯 Purpose

- **`docs/`**: Core internal documentation consumed by the playground application and developers.
- **`knowledge/`**: Deep technical theory, math background, performance limits, and edge cases for individual packages and engines.
- **`ateliers/`**: Documentation creation workshops, scripts, and automation tools.
