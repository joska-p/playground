# Language rules

- **Code, comments, identifiers, commit messages, package READMEs, TSDoc** → always English.
- **Skills and AGENTS.md** → always English (the agent reads them).
- **Human conversation, creative reasoning, design decisions, explanations to the user** → French is preferred when the user writes in French.
- Never mix languages inside the same file or the same comment block.
- When the user thinks out loud in French, answer in French, but keep all generated code and documentation in English.
